# 气泡与背景 · dsh-phone-theme-tool

给 DeepSeek Harness（DSH）Web 界面换一套外观：自己消息和 AI 回复的气泡、输入框、顶栏、侧边栏的颜色，以及对话背景。全部设置都在 **设置 → 气泡与背景** 里，手机竖屏专门适配过。

纯前端插件，不改任何对话内容，不联网，配置只存在本机浏览器存储里。

## 功能

**气泡（我的 / 你的，各自独立）**

- 底色：8 个预设 + 自定义取色；
- 渐变：双色 + 斜 / 竖 / 横三个方向；
- 描边：颜色 + 0–3px 粗细；
- 毛玻璃：半透明 + 背景模糊，强度 2–40px（气泡共用一根）；
- 文字：**常规文字**与**代码文字**分开设置，代码块不会被气泡颜色染黑；
- 文字描边：细暗边，底色和文字太接近时用。

**界面**

- 输入框：颜色 + 独立毛玻璃开关与强度；
- 顶栏：只改颜色，会一并盖住状态栏那一条；
- 侧边栏：只改颜色，同时覆盖 DSH 侧栏自己的底色变量。

**背景**

- 纯色、渐变，或自己的图片（系统选图）；
- 按聊天区实际比例裁剪，拖动定位、滑条缩放；
- 显示方式：铺满 / 拉伸 / 适应 / 平铺；
- 背景模糊 0–24px，只虚化图片，不影响文字。

**预设**

- 把当前整套配置存到本机，随时应用或删除；
- 只存本机，不导出、不上传。

## 安装

要求 DSH ≥ 0.2.0-rc.2（`platform: web`）。

**从 GitHub 安装**（插件页「添加插件」填仓库地址，或命令行）：

```
dsh plugin add github:<你的用户名>/dsh-phone-theme-tool
```

**从 npm 安装**（若已发布）：

```
dsh plugin add dsh-phone-theme-tool
```

**从本地目录安装**：

```
dsh plugin add /绝对路径/dsh-phone-theme-tool
```

安装后在 **设置 → 插件** 里确认已启用，然后重启一次 DSH；打开 **设置 → 气泡与背景** 开始调。

## 说明

- 只改外观：不注入脚本、不改对话数据、不发网络请求；
- 配置与预设存在浏览器 `localStorage`：
  - `dsh.chat-bubble-bg.v1`（当前配置）
  - `dsh.chat-bubble-bg.presets.v1`（预设列表）
  - 清站点数据会一起清掉；
- 顶栏颜色用一层向上的同色阴影盖住状态栏区域，个别机型上边缘可能有一两像素的差异；
- 背景图以 base64 存在本地，图片过大时可能超 `localStorage` 配额，界面会提示。

## 兼容性

- DSH Web（桌面与手机 WebView 都测过）；
- 只在窄屏（≤700px）下做过专门调整；桌面宽屏照常工作；
- 依赖的 DOM 钩子：`[data-chat-flow-kind]`、`[class*="_bubble"]`、`[data-conversation-scroll]`、`[data-composer-card]`、`[data-slot="conversation.header"]`、`[class*="sidebarCol"]`。上游若改这些标记，选择器需要跟着改。
